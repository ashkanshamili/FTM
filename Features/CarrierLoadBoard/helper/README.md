# FTM Carrier Load Board Deployment

## Overview

This package adds the **Carrier Load Board** component to the Salesforce Load record page.

## Deployment Steps

1. Open the FTM GitHub repository.
2. Locate and download the **Carrier Load Board** source code.
3. Deploy the Carrier Load Board code and its included dependencies to the target Salesforce org.
4. Confirm that the deployment completes successfully.

## Add the Component to the Load Record Page

1. In Salesforce, open any **Load** record.
2. Click the **Setup** gear icon.
3. Select **Edit Page**.
4. In Lightning App Builder, find the **Carrier Load Board** component.
5. Drag the component onto the Load record page.
6. Click **Save**.
7. Click **Activate** if Salesforce asks you to activate or assign the page.

The Carrier Load Board is now ready to use on the Load record page.
